## 🍔 Featured Project: NG Restaurant App

A production-grade Food Delivery SPA demonstrating modern React architecture:
- **Global Cart Management:** Built with custom `CartContext` supporting full immutable CRUD operations, steppers, and live header badge counters.
- **Smart Free Delivery:** Orders ₹200 and above unlock free delivery with dynamic nudging.
- **Instant Search & Multi-Filters:** Search by name, cuisine, or price with combinable filter chips (Pure Veg, 4.0+ Rating, Fast Delivery).
- **Fast Bundling:** Powered by Parcel 2 with Hot Module Replacement and PostCSS Tailwind integration.

### Quick Start (NG Restaurant)

```bash
cd restaurant
npm install
npm start
```
Visit `http://localhost:1234` in your browser.
